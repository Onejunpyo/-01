선형 회귀와 비선형 회귀

점들을 입력하면, 그 점들을 가장 잘 따라가는 선을 찾아 줍니다. 값을 바꾸면 결과가 바로 다시 계산됩니다.

처음 사용하는 분을 위한 설명

회귀는 흩어진 점들 사이로 선 하나를 긋는 것입니다. 예를 들어 공부 시간(x)과 시험 점수(y)를 점으로 찍고 선을 그으면, "1시간 더 공부하면 몇 점 오를까?"나 "7시간 공부하면 몇 점일까?"를 알 수 있습니다.

가장 좋은 선은 각 점에서 선까지의 거리(오차)가 전체적으로 가장 작은 선입니다. 이렇게 고르는 방법을 최소제곱법이라고 합니다.

선형 회귀는 곧은 직선을, 비선형 회귀는 휘어진 곡선을 긋는 방법입니다.

사용 순서: ① 왼쪽 표에 x, y 입력 → ② 위쪽 버튼에서 선의 종류 선택 → ③ 식과 그래프 확인 → ④ 아래 표에서 어떤 선이 가장 잘 맞는지 비교

데이터 입력

x와 y를 한 쌍씩 입력합니다. 마지막 칸에서 Enter를 누르면 새 줄이 생깁니다.

xy

선의 종류식R²수정 R²RMSE

행을 누르면 그 선이 선택됩니다. 여러 선을 비교할 때는 수정 R²를 기준으로 합니다. 복잡한 선일수록 R²가 저절로 높아지는데, 수정 R²는 그만큼 감점을 해서 공정하게 비교해 줍니다.

직선(선형 회귀)은 이렇게 계산합니다
지수와 거듭제곱은 로그를 이용해 직선 문제로 바꿔서 계산합니다. 로그는 0보다 큰 수에만 쓸 수 있어서, 지수는 y가, 로그는 x가, 거듭제곱은 x와 y 모두 0보다 커야 계산됩니다.
